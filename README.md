🤖 **AI Companion Usage & Dependency Risk Analysis Dashboard**

📌 **Project Overview**

Explored AI companion usage patterns and their relationships with social interaction, emotional well-being, sleep quality, and dependency risk. Using Microsoft Excel, cleaned and transformed the dataset, created additional analytical columns, and developed an interactive dashboard to analyze user behavior and identify patterns across different demographic and usage groups.

🛠️ **Tools & Technologies**

• **Microsoft Excel** — Data Cleaning, Data Transformation, Analytical Column Creation, and Dashboard Development.

• **PivotTables & PivotCharts** — Data Summarization, Comparative Analysis, and Visualization.

• **Excel Slicers** — Interactive Data Filtering and Exploration.

• **Data Visualization** — KPI Cards, Bar Charts, Pie Charts, Area Charts, and Line Charts.

⚙️ **Key Activities Performed**

• Cleaned and prepared the dataset to improve data consistency and support reliable analysis.

• Created additional categorical columns to classify users by age group, AI usage patterns, and behavioral indicators.

• Analyzed AI chat hours, social interaction, loneliness, emotional attachment, sleep quality, and dependency risk.

• Developed an interactive Excel dashboard featuring KPI cards, charts, and slicers.

• Compared AI usage patterns and dependency risk across demographic groups, chatbot platforms, and primary use cases.

📊 **Dashboard Highlights**

• **AI Usage Analysis:** Examined daily AI chat hours and screen time across chatbot platforms.

• **Emotional Well-Being:** Compared loneliness and emotional attachment patterns across AI usage categories.

• **Primary Use Case Distribution:** Visualized users' primary reasons for interacting with AI companions.

• **Social Interaction Analysis:** Explored average social interaction hours across different age groups.

• **Dependency Risk Analysis:** Examined dependency risk distribution across age groups.

• **Academic & Work Performance:** Compared AI usage and screen time across performance change categories.

• **KPI Monitoring:** Presented total users, average daily AI chat hours, average social media hours, and average sleep quality score.

• **Interactive Filtering:** Enabled dynamic exploration using slicers for age group, chatbot platform, AI usage category, dependency risk, and loneliness category.

💡 **Business & Analytical Value**

Consolidated multiple behavioral and usage indicators into an interactive analytical dashboard, enabling efficient exploration of AI companion engagement, social interaction, emotional well-being, and dependency risk. The dashboard supports data-driven interpretation of user behavior and highlights patterns across different user groups.

✅ **Project Outcome**

Transformed raw data into an interactive Excel dashboard through data cleaning, analytical column creation, and visualization. The project demonstrates practical skills in data preparation, exploratory analysis, behavioral pattern analysis, and dashboard development.
